# Роль: DevOps / CI/CD Engineer

## 📌 Основная цель роли
Обеспечить надёжное, стабильное и предсказуемое окружение для разработки, деплоя и проверки качества.

---

## 🧭 Основные обязанности
- Настройка docker-compose окружения.
- Поддержка локальной разработки.
- Настройка CI (lint, tests).
- Настройка CD (деплой dev/stage).
- Управление переменными окружения.
- Мониторинг технических рисков.

---

## 🎯 Ожидаемые результаты (Deliverables)
- Рабочее локальное окружение.
- CI собирает и проверяет проект.
- Dev-среда доступна для тестирования.
- Документация по запуску обновлена.

---

## 🔧 Процессы, в которых участвует роль
### Перед спринтом:
- Подготовка окружения.
- Обновление скриптов.
- Анализ техдолга DevOps.

### Во время спринта:
- Поддержка сборок.
- Настройка CI/CD.
- Решение инфраструктурных багов.

### В конце спринта:
- Доклад на демо о стабильности сборки.
- Обновление документации.

---

## 🤝 Взаимодействие с другими ролями
- Tech Lead — архитектура сервисов.
- QA — тестовые стенды.
- PO — окружение для демо.
- Docs — документация.

---

## 📚 Навыки, развиваемые в этой роли
- Docker, GitHub Actions.
- CI/CD.
- Сетевые конфигурации.
- Bash/automation.
- Monitoring/observability.

---

## ❓ Частые ошибки и риски
- Сломанное окружение.
- Нет документации.
- Сложные пайплайны.
- Отсутствие логов.

---

## ✔ Чеклист выполнения роли
- [ ] docker-compose работает.
- [ ] CI проходит.
- [ ] Dev-среда доступна.
- [ ] Все переменные окружения описаны.
- [ ] Документация обновлена.

---

## 📝 Примечания
DevOps не обязан писать бизнес-логику.
